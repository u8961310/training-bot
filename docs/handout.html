第 0 關

學會問：請 Gemini 當你的程式小老師

約 5 分鐘

等一下的 Apps Script（GAS）畫面都是程式碼，看不懂很正常。這一關先學會怎麼請 Gemini 寫程式、解釋程式、幫忙除錯；後面關卡看到 🤖 問 Gemini，就是提醒你這時可以拿哪一段提示詞來用。

0

先開好 Gemini 分頁

  1. Chrome 另開一個分頁到 gemini.google.com，用個人 Gmail 登入
  2. 這個分頁一直開著，等一下哪一步看不懂，就切過來問
這裡是「跟 Gemini 聊天」的網頁；第 3 步的 aistudio.google.com 是幫小秘書「拿 API key」的地方，兩個不一樣。

好提示詞＝交代代課老師的四句話

① 角色你是誰
「你是很有耐心的 Apps Script 老師」
② 任務要做什麼
「幫我寫一支每週寄信的程式」
③ 規則哪些不能做
「我不會寫程式，不確定就說不確定」
④ 格式交回什麼樣子
「完整程式碼＋一步一行的操作說明」
❌ 太模糊幫我寫一個提醒研習的程式。
→ 用什麼提醒？提醒誰？什麼時候？Gemini 只能自己猜，寫出來的多半不能用。
✅ 四句話都有你是 Apps Script 老師，幫我寫一支每週日寄信給自己、列出下週研習的程式，我不會寫程式，請附上一步一步的操作說明。
→ 寫出來就能照著貼、照著跑。
最重要的是第 ③ 句。AI 最常犯的錯是「很有自信地亂編」，先說清楚你的程度、要它不確定就講，能少掉一大半麻煩。

GAS 範本 A｜用提示詞產生一支 Apps Script

需求講清楚，再加上幾條「安全規則」，Gemini 就能幫你寫出能直接貼上執行的程式：

✨ 產生 GAS 的提示詞
你是 Google Apps Script 老師，我是不會寫程式的國小老師。請幫我寫一支 Apps Script：

【我要做什麼】
每週日晚上 8 點，寄一封 Email 給我自己，列出下週「研習」日曆裡的所有研習（日期、時間、標題）。下週沒有研習就不要寄。

【規則】
1. 只用 Apps Script 內建功能（例如 CalendarApp、GmailApp），不要用需要 API key 的外部服務。
2. 會改動的設定（日曆名稱、收件人、寄信時間）集中放在程式最上面，用中文註解說明。
3. 另外寫一個 test 函式：只把結果印在執行記錄，不寄信、不刪除任何東西，讓我先測試。
4. 每一段加中文註解。

【交回格式】
1. 完整程式碼（一整段，我會全選貼上）。
2. 一步一行的操作說明：貼在哪、先執行哪個函式、怎麼設定每週自動執行的觸發器。
3. 執行時 Google 會要求哪些權限，各是做什麼用的。

程式寫好之後，照後面關卡的做法跑起來

  • 貼進 Apps Script：新專案 → 全選刪掉預設程式 → 貼上 → 存檔，跟第 4 步一模一樣
  • 先跑 test 函式：下拉選單選 test 開頭的函式 → 執行 → 授權，跟第 6、7 步一樣
  • 有紅字：用範本 B 把錯誤貼回同一段對話，請它給修正後的完整新版
  • 想改功能：接著說「改成寄到另一個信箱」「多列出地點」，改好整段重貼，不要只貼一半
授權畫面看一眼它要的權限：只是寄信給自己，卻要「刪除雲端硬碟檔案」這種不相關的權限，就先別按允許，回去問 Gemini 為什麼需要。會刪除、會大量寄信給別人的程式，一定要先用 test 函式跑過。

GAS 範本 B｜卡關了，貼錯誤訊息求救

🆘 執行出現紅字時用（第 6、7 步最常遇到）
你是很有耐心的 Google Apps Script 老師，我是完全不會寫程式的國小老師。
我在 Apps Script 執行「setup」函式時出現下面的錯誤。

請你：
1. 用一句白話說明這個錯誤是什麼意思。
2. 一步一行，告訴我在畫面上要點哪裡、改什麼。
3. 除非真的必要，不要叫我改程式碼；要改的話，告訴我改哪一行、整行改成什麼。
4. 不確定原因就直接說不確定，不要亂猜。

---- 錯誤訊息 ----
（把執行記錄裡的紅字整段複製貼上）
貼給 Gemini 之前看一眼：錯誤訊息裡如果有 Token、AIza… 開頭的 key，先刪掉再貼。鑰匙只放在指令碼屬性，不給任何人，AI 也一樣。

GAS 範本 C｜看懂一段程式在做什麼

🔍 好奇某個函式在做什麼時用
你是 Google Apps Script 老師。下面是一段程式，請用國小老師聽得懂的話，
分段說明每一塊在做什麼，每段不超過兩句。只要解釋，不要修改程式。

（在 Apps Script 反白一個函式，例如 function setup() { … } 整段，複製貼上）

GAS 範本 D｜想改設定，先問該改哪裡

🛠️ 架好之後想調整時用
你是 Google Apps Script 老師。下面是我這支程式最上面的設定說明。
我想要把每天早報改到 6:30 發送。

請先讀設定說明再回答：
1. 能不能只改「指令碼屬性」就做到？能的話，告訴我屬性名稱和要填的值。
2. 改完還要不要重新執行哪個函式、或重新部署？
3. 如果一定要改程式碼，先告訴我會改到哪裡、有什麼風險，等我同意再給程式碼。

---- 設定說明 ----
（貼上 training-bot.gs 最上面 /** 設定都放「指令碼屬性」… */ 那一整段註解）
以早報時間為例，正確答案是：指令碼屬性加 DIGEST_HOUR = 6、DIGEST_MINUTE = 30，再執行一次 setupTrigger，不用改程式碼。拿這題試試 Gemini 答得對不對。
第 1 關

拿鑰匙：幫小秘書辦電話、裝腦袋

約 15 分鐘
1

開一個 LINE 官方帳號（小秘書的電話）

  1. 電腦開 manager.line.biz，用你的 LINE 帳號登入
  2. 按 建立，帳號名稱填「研習小秘書」，業種隨意選（例如「教育」）
  3. 建好後進入這個帳號，按右上角 設定 → 左邊 Messaging API → 啟用 Messaging API
  4. 「服務提供者」選 建立新的，名稱填你的名字即可 → 同意 → 確定
畫面顯示 Channel ID、Channel secret，就代表啟用成功。
2

拿第一把鑰匙：Channel access token

  1. 同一頁點連結進入 developers.line.biz（LINE Developers），找到剛剛的 channel
  2. 上方分頁切到 Messaging API，捲到最下面 Channel access token
  3. 按 Issue，出現一長串英數字，按旁邊的複製圖示
  4. 先貼在電腦的「記事本」暫放，第 5 步會用到
LINE Developers ─ Messaging API
Channel access token (long-lived)
eyJhbGciOiJIUzI1NiJ9.xxxxxxxx…… Issue
順便在同一頁把 Auto-reply messages（自動回應訊息）設成「停用」，不然每次傳訊息，LINE 都會搶著回一句罐頭訊息。
3

拿第二把鑰匙：Gemini API key（小秘書的腦袋）

  1. 開 aistudio.google.com，用個人 Gmail 登入；第一次會要你同意條款
  2. 點 Get API key → Create API key（要選專案就選預設的）
  3. 複製那串 AIza… 開頭的字，一樣先貼到記事本
記事本裡現在有兩行：一行 LINE token、一行 AIza…。
免費方案不用綁信用卡。完整的 key 只會顯示一次，忘了複製的話，刪掉重建一個就好。
第 2 關

搬進家具：把程式放進 Google Apps Script

約 15 分鐘

Apps Script 是 Google 免費提供的「雲端小電腦」，程式放上去就會 24 小時待命，不用開著你的電腦。

4

建立專案，貼上程式

  1. 開 script.google.com → 左上角 新專案
  2. 點上方「未命名的專案」，改名為「研習小秘書」
  3. 編輯區已經有幾行預設程式碼：點進去按 Ctrl+A 全選，刪掉
  4. 另開分頁到 github.com/u8961310/training-bot → 點 docs → training-bot.gs，按程式碼右上角的 ⧉ Copy raw file 複製全部
  5. 回到 Apps Script 編輯區，按 Ctrl+V 貼上
  6. 按 Ctrl+S 存檔
第一行是 // ===== Config.js =====，存檔後沒有跳出紅色錯誤訊息。
小秘書的程式是寫好的，直接複製就好。以後用範本 A 請 Gemini 寫的新程式，也是照這一步貼進新專案。
5

把兩把鑰匙放進保險箱（指令碼屬性）

  1. 左側點齒輪 ⚙ 專案設定
  2. 確認 時區 是「(GMT+08:00) 台北」，不是的話改過來
  3. 捲到最下面 指令碼屬性 → 新增指令碼屬性，照下表加兩行（左邊一字不差，大寫、底線都要對）
  4. 按 儲存指令碼屬性
專案設定 ─ 指令碼屬性
LINE_CHANNEL_ACCESS_TOKEN（第 2 步那串）
GEMINI_API_KEY（第 3 步 AIza… 那串）
鑰匙放在這裡，而不是寫在程式碼裡，這樣哪天要把程式分享給別人，也不會連鑰匙一起送出去。
6

執行 setup，讓它自己建日曆與試算表

  1. 回到 <> 編輯器，上方工具列的函式下拉選單選 setup → 按 ▷ 執行
  2. 跳出「需要授權」→ 審查權限 → 選你的 Gmail
  3. 看到「Google 尚未驗證這個應用程式」→ 點左下 進階 → 前往「研習小秘書」（不安全） → 允許
為什麼寫「不安全」？因為這支程式是你自己的，沒送 Google 審查。它要的權限（日曆、試算表、雲端硬碟、寄信、連外網）都是給你自己的小秘書用的。
執行記錄
已建立日曆：研習 已建立試算表：https://docs.google.com/spreadsheets/d/…… 已建立講義資料夾：https://drive.google.com/drive/folders/…… 早報觸發器：每天 7:30 左右 ⚠️ 還沒設定：ALLOWED_USER_IDS
看到上面五行就對了。最後一行的 ⚠️ 是正常的，第 11 步才會補上。
想知道 setup 到底做了什麼？在編輯區反白整個 function setup() { … }，用範本 C 請 Gemini 解釋。執行跳紅字就用範本 B。
7

執行 testExtract，確認腦袋會動

  1. 下拉選單改選 testExtract → ▷ 執行
  2. 等 3–10 秒，看下方執行記錄
記錄裡出現一段有 "title"、"date"（9 月 28 日）、"start": "19:00" 的文字，就代表 Gemini 讀得懂公告。
如果出現 API key not valid：回第 5 步檢查 GEMINI_API_KEY 有沒有貼完整、前後有沒有多空白。
出現其他紅字看不懂？用範本 B，把執行記錄的紅字貼給 Gemini（先刪掉裡面的鑰匙）。
第 3 關

接上電話線：讓 LINE 找得到小秘書

約 15 分鐘
8

部署成「網頁應用程式」，拿到門牌網址

  1. 編輯器右上角 部署 → 新增部署作業
  2. 「選取類型」旁的齒輪 → 選 網頁應用程式
  3. 執行身分：我；誰可以存取：所有人 → 部署
  4. 複製畫面上的「網頁應用程式」網址（https://script.google.com/macros/s/……/exec）
把網址貼到瀏覽器新分頁打開，畫面只出現一行 training-bot OK。
「所有人」是為了讓 LINE 伺服器打得進來。這個網址等於小秘書的門牌，不要公開分享；陌生人就算知道，第 11 步的白名單也會擋住。
9

把門牌填到 LINE（Webhook）

  1. 回 LINE Developers → 你的 channel → Messaging API 分頁
  2. Webhook URL 按 Edit，貼上第 8 步的網址 → Update
  3. 把下面的 Use webhook 開關打開（變綠色）
旁邊的 Verify 按下去可能顯示錯誤（Google 會多轉一次網址），不用理它，以第 10 步實測為準。
10

手機加好友，問出你的 userId

  1. 同一頁上方有 QR code，用手機 LINE 掃描 → 加入好友
  2. 傳一句「你好」給小秘書
你好
🔧 設定模式
你的 userId：
U1a2b3c4d5e6f……

把它填進指令碼屬性 ALLOWED_USER_IDS 就能開始用。
收到「🔧 設定模式」這則回覆，代表電話線接通了！
傳了沒反應？九成是第 9 步的 Use webhook 沒打開，或第 2 步的自動回應訊息沒關。
11

把自己加進白名單

  1. 在手機上長按那串 U…… 複製，用 LINE 傳給自己的電腦版，或直接在電腦版 LINE 複製
  2. 回 Apps Script → ⚙ 專案設定 → 指令碼屬性 → 新增第三行：
    ALLOWED_USER_IDSU1a2b3c4d5e6f……
  3. 儲存。不用重新部署，馬上生效
要讓家人也能用？多個 userId 用半形逗號隔開。不過大家的研習都會寫進同一本日曆，建議每個人各自架一套。

日曆上出現「💻 資訊素養增能研習」，報名截止那天也多了一個「⏰ 報名截止」的全天事件。恭喜，完成了！

之後每天怎麼用

  • 看到公告就丟給它：文字或截圖都可以。只貼網址不行（臉書要登入才看得到，它讀不到）
  • 卡片標題的圖示：🏫 實體、💻 線上、🔀 混合；公告沒寫的欄位會空著，AI 不會自己猜
  • 看到紅字「⚠️ 日期時間信心偏低」：AI 不太確定，一定要對照原文再按 ✅
  • 它只負責抄，不會幫你報名，報名連結還是要自己點
  • 研習後把講義檔或連結丟給它：點選是哪一場，就會存進雲端硬碟「研習講義」資料夾（Google 簡報／文件連結會另存 PDF 備份）；之後輸入 講義 關鍵字 就找得到

沒架小秘書也能用：在 Gemini／ChatGPT 下提示詞

回家延伸

小秘書的腦袋，其實就是一段事先寫好的「提示詞」。用第 0 關學的四句話，打開 Gemini 或 ChatGPT 網頁一樣能幫你整理研習、摘要講義、寫心得。

範本 1｜研習公告 → 整理成資訊表（兩邊都能用）

整段複製貼上，黃底的地方換成你的內容。公告是圖片或 PDF 的話，直接把檔案一起丟進去。

範本 2｜Gemini 直接幫你寫進 Google 日曆

  1. 開 gemini.google.com，用個人 Gmail 登入（跟日曆同一個帳號）
  2. 第一次用先到 設定 → 應用程式，確認 Google Workspace（含日曆）是開啟的
  3. 貼上範本 1 的結果或公告原文，再接著輸入：
📅 接著輸入
@Google 日曆 把上面這場研習加到我的「研習」日曆，
標題用研習名稱，說明欄放地點或會議連結。
報名截止那天另外加一個全天事件，標題是「⏰ 報名截止：研習名稱」。
加之前先列出你要建立的內容讓我確認。
最後一句「先列出來讓我確認」很好用：它會先給你看，你回「好」才真的寫進去。日曆名稱填你自己有的那本，沒有就寫「主要日曆」。
ChatGPT 沒辦法直接寫進你的 Google 日曆：用範本 1 整理好之後，自己到日曆新增就好。

下提示詞的三個好習慣

  1. 不滿意就接著說，不用重來：「第二場的時間再對一次原文」「改成條列」「再短一點」，AI 會在同一段對話裡修改
  2. 貼全文，不要只貼網址：臉書、校內系統要登入才看得到，AI 讀不到就會亂猜
  3. 個資不要貼：學生名單、成績、身分證字號都別丟進去，跟使用小秘書的規矩一樣

使用安全三件事

  1. 含個資的內容不要傳（學生名單、身分證字號）。公告會送到 Gemini 免費方案處理，免費方案的資料可能被拿去改進模型。一般研習公告本來就是公開資訊，沒關係
  2. 鑰匙和門牌網址不外流：Token、API key、Web app 網址都只放在自己的專案裡
  3. 按 ✅ 前看一眼日期時間：這是整套流程裡最重要的一個動作
